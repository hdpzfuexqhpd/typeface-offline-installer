# Typeface — Free Offline Installer

![Category](https://img.shields.io/badge/Font_Manager-blue?style=flat-square)

## About

Typeface is an elegant macOS font manager designed for designers who care about their tools. Browse your font collection with beautiful previews, organize fonts into smart sets, and activate fonts for any project with one click. With integration for Adobe apps, Sketch, and Figma, Typeface seamlessly fits into modern design workflows while keeping your font library organized.

## Common Problems & Limitations

- **macOS Only** — No Windows version
- **Paid Application** — One-time purchase required
- **System Font Integration** — Advanced system font management requires care
- **Performance** — Very large font collections may affect preview speed
